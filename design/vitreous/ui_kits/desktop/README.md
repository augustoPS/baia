# UI kit — Desktop

The system chrome around apps: transparent menu bar with a live menu, two layered windows (one
inactive), Control Center, Spotlight-style palette, and a magnifying Dock.

- ⌘Space or ⌘K toggles the palette; ⎋ dismisses everything.
- The floating HUD strip above the Dock switches dark/light and toggles Control Center and the palette,
  so reviewers can see the glass over the same wallpaper in every state.
- Dock tiles are lettered placeholders — this system ships no icon set (see readme.md → ICONOGRAPHY).
