# UI kit — Menu-bar utility

An app with no window: a status item in the menu bar opens a `Popover` that *is* the app, plus a
Control Center panel for comparison.

- Click **2 agents** or **Control Center** in the menu bar to open each panel; clicking the item again closes it.
- The agent popover shows the pattern for utilities: state first (running work, cost), one mode control,
  one primary action, and a way into the full app. Everything is 300–320px wide.
- The HUD card in the middle switches appearance and tinted glass so the panels can be reviewed in all modes.
