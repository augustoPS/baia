# UI kit — Chat

Conversation list plus thread and a glass composer.

- Sending a message appends it live (⏎ sends, ⇧⏎ newline); a typing indicator sits at the end of the thread.
- Own messages take the accent fill; received messages are thin glass. Agent conversations get a caution
  marker in the sidebar so an approval request is visible from the list.
- The Info button opens a `Popover` anchored inside the window.
