# UI kit — Code editor

Editor window: changed-files sidebar, document tabs with a dirty dot, a diff-tinted source pane with a
gutter, and an inspector with Diff / Problems / Test tabs.

- Added and removed lines tint with `--status-positive` / `--status-negative` at 12% over glass, so the
  wallpaper still shows through.
- The status bar carries the platform-standard caret position, language, encoding and line ending.
