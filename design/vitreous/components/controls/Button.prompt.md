Standard push button at platform metrics (20/22/28/32px heights).

```jsx
<Button variant="accent" keyEquivalent="⏎">Run agent</Button>
<Button>Cancel</Button>
<Button variant="glass" size="small">Stop</Button>
<Button variant="destructive">Delete session…</Button>
```

One `accent` per window. `glass` only over content or imagery — never inside an already-glass toolbar, where `push` reads correctly.
