# App icons

Run `swift Icon/make-icon.swift` from the repository root to regenerate both ICNS files with native AppKit and `iconutil`.

`baia-dev.icns` uses the flat angular **b** approved on 2026-10-20. The tall divider and short, low chevron form a terminal-derived letter. The field is `#14191b`; the mark is `#eeeade`. There is no Debug badge or alternate color.

The owner supplied the name's origin: Kimbundu *ribaia*, a compartment made by dividers. The divider and command notation form the letter together.

The 1024px master has an 824px tile inset by 100px, with a 181px corner radius. Master mark coordinates are transformed into that tile. The 16px and 32px representations use the separately approved optical geometry. All ten standard macOS iconset slices are rendered at their actual pixel size.

`baia.icns` retains the legacy Release identity. This app adoption is limited to the development build. The website adopted the approved mark separately on 2026-10-20.
